# SE-4385-Group-9
A cloud-based platform for tracking employee skills across complex organizational structures. The system connects a standardized Skills Catalog, Organization Structure, and Skills Inventory to provide a clear view of workforce capabilities and how skills are distributed across employees, roles, and teams.

### Setup
Install Node.js and run in terminal:

```bash
cd frontend
npm install
npm run dev
```
Open the local URL printed in the terminal.

### Additional Commands:
- `npm run build` — check TypeScript and build for production.
- `npm run lint` — check for code issues.
- `npm run preview` — preview the production build after building.
